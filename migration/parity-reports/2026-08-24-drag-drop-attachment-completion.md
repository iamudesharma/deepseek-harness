## Flutter implementation
- Thumbnail seam: `widgets/attachment_image.dart` facade `export 'attachment_image_stub.dart' if (dart.library.io) 'attachment_image_io.dart'`; `stub` returns fallback `Container Icon(image_outlined)` for web (no `dart:io`), `io` returns `Image.file(File(path), cover, errorBuilder→fallback)` for rail and `Image.file(contain)` for lightbox with placeholder fallback; `widgets/attachment_rail.dart` now uses `buildNativeThumbnail(url, aliases)` and `buildNativeLightbox(url, aliases, name)` for `url.startsWith('/')` (native path) while `http/blob:/data:` stays `Image.network`, so `flutter build web` never imports `dart:io` and macOS renders file thumbnails.
- Deduplication: `platform/drag_drop.dart` owns single source `ImageLimits {mediaTypes,maxImagesPerMessage,maxImageBytes,maxMessageImageBytes}`, `DroppedFile {name,mimeType,size,path,bytes?:Uint8List}`, `imageSizeText(bytes)→B/KB/MB`; `DragDropController` `_sizeText` now delegates to `imageSizeText` and `limitsText` uses the same function; `plugins/attachment/attachment_limits.dart` re-exports `ImageLimits, DroppedFile, imageSizeText` and keeps only `imageLimitsProvider`; no duplicated class or `KB/MB` logic.
- DocumentDropScope modal guard: added `enabled=true` param plus `ModalRoute.of(context)?.isCurrent` check → `effectiveEnabled = enabled && isTopRoute`; when false returns `child` only and resets stale `dragActive` via post-frame `controller.reset()`, otherwise `DropTarget` with `onDragEntered/Exited/Done`; `onDragDone` now reads `file.readAsBytes()` into `DroppedFile.bytes` alongside `length`; overlay only rendered when `controller.dragActive` and `effectiveEnabled`.
- Serialization seam: `platform/drag_drop.dart:DroppedFile` carries `bytes`, `features/conversation/composer_controller.dart:ComposerAttachment` carries `bytes`, `ComposerAttachment.create({bytes})` stores it; `plugins/conversation/ui/composer.dart:intakeComposerImages` propagates `file.bytes` into `ComposerAttachment.create(bytes:)`, `DocumentDropScope` and `_pickImages` now capture bytes (`desktop_drop readAsBytes`, `file_picker withData:true bytes`); `platform/attachment_bytes.dart` conditional seam `readFileBytes(path)` (`stub→null`, `io→File.readAsBytes`) allows lazy read at submit time for attachments whose bytes were not captured; `core/connection/connection_client.dart:sendMessage({sessionId, content, mode, clientTimeZone, images=[]})` now builds `contentParts = [...images, if(text non-empty) {type:'text'}]` and posts `session.prompt`; `ComposerController.serializeDraftImages` validates `mediaType` against `{'image/png','image/jpeg','image/webp','image/gif'}`, reads bytes via `attachment.bytes ?? readFileBytes(path)`, throws on unsupported type or missing data, `base64Encode(bytes)` and emits `{type:'image', mediaType, data, name?}`; `ComposerController.submit` now serializes draft images before optimistic clear, surfaces serialization error as `state.error` without clearing draft, otherwise sends `images` plus `text` via `client.sendMessage` and clears draft on success (keeps `selectedModel`), restores draft on host failure.
- Staging consolidation: `features/conversation/composer_controller.dart` is canonical `ComposerAttachment` owner; `features/attachment/attachment_provider.dart:composerAttachmentsProvider` marked `@Deprecated` demo with fake data (now points to `composerControllerProvider(sessionId)`), `plugins/attachment/attachment_service.dart:AttachmentStagingService` marked `@Deprecated` with notice and retained only for `ws_surfaces` fixture `host.service(kAttachmentsServiceName)` assertion; new code uses `composerControllerProvider(sessionId)` per-session.

## Decisions
- Kept `desktop_drop` unified `DropTarget` for web+macOS; document-level via `DocumentDropScope` wrapping conversation hero+column matches React `document` listeners for the conversation viewport without global listeners.
- Chose conditional import facade `if (dart.library.io)` over `kIsWeb` guard with direct `dart:io` import because direct import breaks `flutter build web` even when guarded; facade keeps web artifact `dart:io`-free while macOS gets `Image.file`.
- Made `imageSizeText` and `ImageLimits` single-source in `platform/drag_drop.dart` and re-exported from `attachment_limits.dart` to keep platform as low-level owner and avoid `platform → plugins` upward import; controller now uses the shared function so limits line and pre-check messages stay identical.
- Added `enabled` plus `ModalRoute.isCurrent` guard instead of a new provider because the existing `ModalRoute` stack already tracks `Dialog`/`showDialog` front-layer state; `effectiveEnabled` disables both `DropTarget` and overlay while a modal is on top, mirroring React disabling document listeners behind modals; explicit `enabled` allows caller to bind to other front-layer signals if needed.
- Propagated `Uint8List? bytes` through `DroppedFile → ComposerAttachment → serializeDraftImages` and captured bytes at intake (`readAsBytes` / `withData:true`) so `submit` can synchronously base64-encode without re-reading files; lazy `readFileBytes` fallback covers picker/drop paths where bytes were not captured and native path still needs reading at submit time, matching React keeping `File` object until `file.arrayBuffer()`.
- Extended `ConnectionClient.sendMessage` with `images` param rather than introducing a new method to keep the canonical `session.prompt` path single; image parts are ordered before text block as React's `[...uploaded, text?]`, and empty-text-with-images correctly sends only image blocks.
- Deprecated `AttachmentStagingService` and `composerAttachmentsProvider` instead of deleting to keep `ws_surfaces` `host.service` assertion and existing `attachment_screen.dart` demo compiling; tracker notes the migration path and removal condition.
